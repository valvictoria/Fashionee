Fashionee (интернет-магазин)

1. Описание приложения 

Приложение представляет собой интернет-магазин, где пользователи могут: 
 - Просматривать товары, фильтруя их по названию, категории, цвету, цене и другим параметрам; 
 - Добавлять товары в корзину, изменяя их количество; 
 - Добавлять товары в избранное; 
 - Применять промокоды для получения скидок; 

 Основные функции: 
 - Фильтрация товаров по названию, категории, цене и цвету;
 - Сортировка товаров по имени (по возрастанию и убыванию);
 - Пагинация для удобного просмотра списка товаров;
 - Добавление товаров в корзину с сохранением в LocalStorage;
 - Добавление товаров в избранное с сохранением в LocalStorage;
 - Применение промокодов.

2. Технологии и инструменты (стек)

 - React JS
 - React Router: маршрутизация между страницами (переход между магазином (Shop) и корзиной (Cart))
 - Context API: управление состоянием приложения (фильтры, корзина, избранное)
 - Local Storage: сохранение данных корзины и избранного после перезагрузки страницы, а также при переходе между страницами;
 - CSS: стилизация компонентов.

 3. Описание компонентов

 - App: главный компонент приложения, объединяет все страницы и провайдеры контекста. Обеспечивает маршрутизацию между страницами, оборачивает приложение в провайдеры контекста. 

 - Shop: главная страница интернет-магазина. Отображает товары с учетом примененных фильтров, включает компоненты для сортировки, фильтрации и пагинации. 

 - Sidebar: боковая панель страницы Shop, которая позволяет пользователю выбирать категорию, цвет и ценовой диапазон. Осуществлять поиск по наименованию. Кнопка Apply Filter применяет выбранные фильтры. 

 - Cart: страница корзины. Отображает список товаров корзины, управляет их количеством. Рассчитывает итоговую стоимость заказа с учетом доставки и примененных скидок, с использованием промокода.

 - Header: содержит меню навигации, отображает счетчики для товаров в корзине и избранном; 

 - Footer: содержит контактные данные и способы оплаты. 

 4. Логика работы приложения

 - Фильтрация товаров: 
 фильтрация происходит на основе состояния, хранящегося в FiltersContext. Пользователь выбирает категорию, цвет и ценовой диапазон, после чего нажимает кнопку "Apply Filter". Фильтры применяются к списку товаров, который отображается на странице магазина.
 Использование контекста позволяет централизованно управлять состоянием фильтров и передавать его между компонентами без необходимости прокидывать пропсы через множество уровней.

 - Корзина: 
 данные корзины хранятся в CartContext и сохраняются в LocalStorage. Пользователь может добавлять товары в корзину, изменять их количество или удалять.

 - Избранное: 
 данные избранного хранятся в FavoritesContext и также сохраняются в LocalStorage. Пользователь может добавлять или удалять товары из избранного.

 - Сортировка: 
 пользователь может выбрать один из вариантов сортировки: по релевантности, по имени (возрастанию или убыванию). При изменении выбора в <select>, значение сортировки передается в setSortOrder, что обновляет состояние sortOrder в компоненте Showcase.

 - Пагинация: 
 товары разбиваются на страницы с фиксированным количеством элементов (12 товаров на страницу). Пользователь может переключаться между страницами с помощью компонента Pagination.
